# Identidade aplicada em 31/10/2026

A logo enviada por Kaio é a referência vigente. O PNG transparente original está em `public/brand/logo-ka.png`; o PNG com fundo está nesta pasta. Os pixels dos arquivos foram preservados.

O componente `LogoArtwork` exibe o desenho completo, o monograma ou o nome por meio de viewports SVG sobre a mesma imagem. O nome do menu usa as próprias letras fornecidas, sem atribuir uma fonte desconhecida. No tema claro, apenas o nome recebe contraste escuro por CSS.

`public/favicon.svg` é uma adaptação vetorial compacta desenhada para a aba do navegador: mantém o KA, a curva violeta do A e fundo escuro. A moldura, o nome e o símbolo de código ficam de fora nessa escala. Não é uma vetorização completa da logo original.

## Avaliação e refinamentos sugeridos

O contraste branco/violeta e o A com travessa curva dão unidade à marca. A moldura e o símbolo de código reforçam a associação com desenvolvimento. A composição completa funciona melhor em tamanho médio ou grande.

- Para ícones pequenos: usar apenas KA, conforme a adaptação entregue.
- Em uma próxima revisão: harmonizar os terminais retos do K com os arredondados do A.
- Para impressão e ampliações: preparar uma versão vetorial completa e uma versão de uma cor, revisadas pelo autor. Os PNGs continuam sendo originais raster, não vetores.

A marca principal foi preservada; nenhuma proposta alternativa substituiu o desenho escolhido.
